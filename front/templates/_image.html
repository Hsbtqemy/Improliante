{% comment %} Une image de média. Attend `media` (un `Media` de type image). Pose les trois choses que l'audit demandait sous « variantes et dimensions connues » : - `srcset` vers la VIGNETTE (600 px) quand elle existe, pour qu'un téléphone ne télécharge pas une image de 2 000 px dans une carte de 300 ; - `sizes`, sans quoi le navigateur suppose toute la largeur de l'écran et reprend la grande — c'est le paramètre `tailles`, à donner selon la place réelle de l'image ; - `width`/`height` intrinsèques, pour réserver la place avant l'arrivée du fichier. La CSS l'emporte sur ces attributs : ils ne déforment rien. Paramètres : `classe`, `tailles`, `decoratif` (alt vide, image redondante avec le texte voisin), `prioritaire` (image principale d'une fiche, visible d'emblée — pas de chargement différé), et `largeur_affichee` pour un aperçu dont la taille est fixée par le gabarit (les écrans de gestion) : les dimensions sont alors mises à l'échelle, pour garder le rapport sans imposer 2 000 px de large. Une image de BROUILLON n'a pas d'URL publique : elle vit hors de la racine web et passe par une vue qui contrôle les droits. Elle n'a pas non plus de vignette — une miniature dans le stockage public serait une fuite de l'image protégée —, donc le `srcset` ci-dessous ne la concerne pas. {% endcomment %}
